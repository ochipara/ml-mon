⚡ Antigravity Agent Lifecycle & Architecture

🌐 Remote LLM vs. 💻 Local IDE Execution

Not every step in an agent session is a network roundtrip to the remote model. The agent loop alternates between purely local IDE operations and remote LLM inferences:

Step Type Origin / Source Location Description
Chain of Thought (CoT) MODEL / PLANNER_RESPONSE 🌐 Remote Gemini generates internal reasoning & planning tokens.
Tool Proposals MODEL / PLANNER_RESPONSE 🌐 Remote Gemini requests a tool call (e.g. run_command, view_file) with JSON args.
Assistant Response MODEL / PLANNER_RESPONSE 🌐 Remote Gemini returns final markdown answer to user.
User Request USER_EXPLICIT / USER_INPUT 💻 Local IDE captures your prompt, open tabs, cursor position, and terminal state.
Conversation History SYSTEM / CONVERSATION_HISTORY 💻 Local IDE indexes and formats past conversation summaries from disk.
Knowledge Items SYSTEM / KNOWLEDGE_ARTIFACTS 💻 Local IDE queries local Knowledge Items database for matches.
Tool Result Execution SYSTEM / RUN_COMMAND etc. 💻 Local IDE executes shell commands or edits files on your host Mac. Model is idle.
Compaction Checkpoints SYSTEM / CHECKPOINT 💻 Local IDE runtime prunes older turns and resets active context to a summary.

🔄 Agent Turn Execution Sequence

Here is how a turn flows between the user, the local IDE runtime, and the remote Gemini LLM:

Step 0 💻
User Prompt: You submit a prompt. The IDE gathers active document, cursor line, and open workspace metadata.
Steps 1-2 💻
Context Assembly: IDE injects recent conversation history summaries and matches knowledge items from local cache.
Step 3 🌐
Remote Model Call: Active context is sent to Gemini. Model streams back Chain of Thought + requests a Tool Call (e.g. list_dir).
Step 4 💻
Local Tool Execution: IDE runs the command/tool on your Mac filesystem and captures stdout/stderr.
Step 5 🌐
Model Feedback: IDE sends tool output to Gemini. Model reasons further and proposes next tool (e.g. view_file).
Final 🌐
Assistant Response: When finished, Gemini generates the final response rendered in the chat window.

⚡ Context Window Evolution & Compaction

Active Window (Sawtooth): Measures tokens in the LLM's active attention window. Each tool output adds tokens. When the context budget is reached, a compaction checkpoint drops older turns, creating a sharp cliff drop back down to the baseline summary.

Cumulative Session: Monotonically tracks total context processed across the entire conversation history.
